Suggested technical design / v2

SSO without rewriting identity.

在现有认证边界之外新增协议适配层，以可回退的账户绑定机制和分阶段开关控制迁移风险。设计目标是最大化复用、隔离协议复杂度并保持本地登录可用。

Design intent

Three non-negotiables

技术方案围绕可逆性、隔离性和可审计性展开，而不是把 SSO 直接耦合进现有登录流程。

Local login survives

SSO 异常时保留受控本地登录回退，避免身份提供方故障扩大为平台级中断。

Protocol stays isolated

SAML 解析、证书和 metadata 由适配层处理，业务会话只接收标准身份声明。

Migration is reversible

账户绑定分批执行，保留映射历史、冲突队列与可验证回滚路径。

每个增量都可独立验证，且在进入下一阶段前保留明确回退点。

建立适配接口、SAML fixture、证书校验和审计事件模型。

Test strategy

Prove the boundaries

Assertion contract

有效、过期、重放、错误受众和签名异常。

IdP variations

不同 metadata、NameID 和属性映射组合。

Certificate lifecycle

轮换、过期、双证书窗口与时钟偏差。

Dry-run parity

预演结果与实际迁移数量、冲突类型一致。

Rollback proof

恢复映射快照后本地登录行为不变。

Conflict handling

重复邮箱、孤儿用户与手工裁决流程。

IdP outage

超时、错误提示和受控本地回退。

Partial rollout

租户级开关隔离与监控指标分群。

Audit completeness

成功、失败、配置和绑定事件完整留痕。

Risk controls

Known uncertainty, explicit guardrails

账户错误绑定HIGH

使用预演、冲突队列、双人审核和版本化映射；禁止按邮箱静默覆盖。

证书轮换中断HIGH

支持双证书窗口、提前告警、连接测试与紧急回退。

IdP 可用性MEDIUM

短超时、清晰错误状态、受控本地登录和租户级禁用。

权限漂移MEDIUM

外部身份只映射本地账户，权限继续由现有引擎管理。

Design recommendation

Proceed—with migration as the gate.

先验证账户数据与冲突率，再锁定最终范围。架构本身可复用且风险可隔离。
